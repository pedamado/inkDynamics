1. Overcoming the "Sterile Digital Line"

Aesthetic & Assistive Rationale

In eye-gaze and assistive drawing interfaces for Locked-In Syndrome (LIS), Amyotrophic Lateral Sclerosis (ALS), and severe motor impairments, digital lines are universally rendered as sterile geometric vectors: uniform poly-lines, monotonic Bezier curves, or plastic anti-aliased tubes. While technically stable, these marks lack kinematic soul, viscous resistance, and organic unpredictability.

1. Instrument Nib Mechanics

Multi-bristle elastic hair tufts, soft compressible foam domes, and dual flexing spring-metal leaves that clamp, bend, and release under paper friction.

2. Ink Rheology & Fluidics

High-fluidity carbon Sumi ink vs heavy thixotropic acrylic paint. Capillary feeding, surface tension bead formation, dwell pooling, and gravity cascades.

3. Paper Substrate Tribology

Microscopic tooth texture, cold-press cartridge roughness, capillary absorption, and harmonic paper tooth boundary perturbation.

4. Kinematic Gesture Dynamics

Eye-gaze velocity, dwell hesitation pooling, sudden saccadic accelerations, and spring release vibration claps.

3. Curved Ruling / Folded Cola Pen

ruling_pen_curved
Simulation v3.8 Elastic Blade Physics

Models the side-drag of two curved spring-brass plates clamped together. Calibrated to the expressive techniques of modern calligraphers: 60° angled pill ellipse touchdowns, inverted friction skips (dense ladder vs wide skips), volcano pressure-release catenary decay curves, and directional provenance spit droplets angled back to origin.

Figure 3.1: Curved Ruling Pen Macro Reference
Symmetric curved blade side showing dense cross-bars, friction skipping, and explosive ink spit bursts.
Figure 3.2: Calibrated Friction Skips & Claps
High velocity produces wide skips with volcano-like pressure bursts that decay via a catenary curve.
Figure 3.3: Blade Angle & Provenance Splats
Spit droplets explode perpendicularly, with major diameters oriented back to the instantaneous origin point.
Volcano Pressure-Release Catenary Decay Formulation
$$W(u) = W_{\text{base}} \cdot \left[ 1 + E_{\text{burst}} \cdot \frac{\cosh(k(1 - u)) - 1}{\cosh(k) - 1} \right]$$
Where \(u \in [0, 1]\) is the normalized decay progress along the burst recovery trail, \(E_{\text{burst}}\) is the momentary clap explosion width multiplier (controlled by spitBurstExplosionWidth), and \(k = 3.6\) is the steepness parameter. This produces an ultra-fast initial pressure release followed by a smooth catenary relaxation back to baseline line width.

4. Flat Ruling / German Expressionist Chisel Pen

ruling_pen_flat
Simulation v3.8 Asymmetric Chisel Physics

Models the wide flat-ground steel chisel ruling pens popularized by mid-century German expressionist calligraphers. Characterized by high-frequency "soundwave-like" chatter, dual parallel "train tracks" from the outer corner leaves, and asymmetric edge behavior (one edge remains razor-sharp while the other explodes in chatter waves).

Figure 4.1: Flat Ruling Pen Macro Reference
Large flat nib exhibiting high-frequency soundwave edge chatter, dual train tracks, and dense cross bars.
Figure 4.2: Train Tracks & Asymmetric Edge Chatter
Outer corners create continuous parallel guide lines; high velocity clears the center into elliptical skips.
Figure 4.3: Flat Nib Curved Gestures
Curving the flat nib twists the corner contact, producing explosive splats up to 3x line width on the convex side.
Directional Spit Droplet Provenance Formulation
$$\theta_{\text{droplet}} = \operatorname{atan2}(y_{\text{drop}} - y_{\text{origin}}, x_{\text{drop}} - x_{\text{origin}})$$
Each microscopic expelled spit droplet computes its angle directly from the parent burst origin coordinate on the stroke centerline. Its major ellipse axis is aligned along \(\theta_{\text{droplet}}\), while its eccentricity \(e = \sqrt{1 - (b/a)^2} \ge 0.82\) provides visual evidence of explosive centrifugal expulsion.

5. Ink That Mixes — Transparency, Overprint & Capillary Intersection Micro-Swell

OverprintBlender.js
Simulation v4.0 · 'mix' Spatial Ink Grid + Capillary Bleed Open Live Specimen Lab ↗

Ink is never quite opaque: a stroke lets a little of the paper — and of the strokes beneath — show through, and where a wet stroke crosses earlier ink the two mix, as overprinted inks do. In 4.0 every colour (white and very light ones too) is laid at 97% density; at crossings it moves toward the overprint (multiply) of the two inks as far as the blending intensity says. Black stays black (#070707 on Munken paper) and two blacks crossing are slightly blacker (#000000). The mix comes in fast once the nib meets the ink beneath and is given back slowly after it — the pigment picked up is carried on. Across the crossing the line swells by 5–10%, by ink: least in fast-running, quick-drying drawing ink (ruling pens), most in heavy acrylic (Posca).

1. Transparent ink, mixed like an overprint
\( B = P + (U - P)k,\quad S = \rho C + (1-\rho)B,\quad M = \tfrac{C\cdot B}{255},\quad D = S + (M - S)\,kI \)
\(C\) the ink, \(U\) the ink beneath, \(P\) the paper, \(k\) the crossing strength, \(\rho\) = inkDensity (0.97), \(I\) = overprintDarken (the blending intensity, 0.45). \(D\) is painted opaque, so the 15–36 overlapping sub-paths of one stroke never build up into bands — on an opaque canvas or a transparent layer alike.
2. Fast in, slow out — and the swell
\( k \leftarrow k + (c - k)(1 - e^{-\Delta s/L}),\quad L_{\text{in}} = r(0.12 + 3(1-a)^2),\ L_{\text{out}} = r(0.25 + 12(1-b)^2),\quad R_{\text{eff}} = R_0(1 + \sigma k) \)
\(c\): how much of the nib (within overprintReach × r) lies over ink beneath — another stroke, or an earlier loop of this one (\(\Delta s > \max(26\text{px}, 4.2R_0)\)). \(a\) = overprintAttack, \(b\) = overprintRelease, \(\sigma\) = the instrument's overprintSwell (ruling 5% · Zig 7.5% · Posca 10%).

4. Developer Integration & Host API Reference

ES6 Architecture

InkDynamics is distributed as a zero-dependency, modular ES6 library. It operates directly on any HTML5 <canvas> element and supports single-user gaze input, touch/mouse pointers, and multi-agent boid swarms via parallel channels.

1. Instantiation

import { createInkDynamics } from './js/inkdynamics.js'; // Factory initialization const ink = createInkDynamics({ canvas: document.getElementById('drawing-canvas'), tool: 'ruling_pen_curved', // 'chinese_brush' | 'posca_squeezer' | 'ruling_pen_curved' | 'ruling_pen_flat' preset: 'curved_ruling_medium', // Active calibration preset color: '#191817', // Pigment hex or token thickness: 'medium', // 'hairline' | 'thin' | 'medium' | 'thick' | 'broad' | number in px paperTooth: 0.45, // Substrate texture (0.0 smooth to 1.0 coarse) overprintModel: 'mix', // v4.0: 'mix' (transparent ink that mixes) | 'classic' (3.9) inkDensity: 0.97, // v4.0: 97% — 3% of the paper / strokes beneath shows through overprintDarken: 0.45, // v4.0: blending intensity at crossings overprintAttack: 0.85, // v4.0: approach mix speed overprintRelease: 0.55, // v4.0: exit restore speed paperColor: '#F4F1EA', // v4.0: the paper under the ink autoStep: true // Drives gravity drip loop automatically via requestAnimationFrame });

2. Kinematic Event Loop

// 1. Touchdown contact (Stamps bone-head / angled pill ellipse) ink.penDown(x, y, pressure = 0.5, timestamp = performance.now(), agentId = 0); // 2. Drag motion (Calculates dt, velocity, starvation & tension claps) ink.penMove(x, y, dt = null, pressure = 0.5, timestamp = performance.now(), agentId = 0); // 3. Lift termination (Calculates flick tapering or lift puddle) ink.penUp(x, y, timestamp = performance.now(), agentId = 0);

3. Multi-Agent Boid Swarms & Dual-Seat Carer Channels

// Agent 0 (Primary User / Eye Gaze) ink.penDown(userX, userY, 0.5, now, 0); // Agents 1..8 (Simultaneous Autonomous Boid Agents or Carer Hands) ink.penDown(boid1.x, boid1.y, 0.4, now, 1); ink.penDown(boid2.x, boid2.y, 0.6, now, 2);

4. Runtime Ink Mixing & Micro-Swell Controls (v4.0)

// The ink's mixing at runtime (every value tunable) ink.setBlendMode('multiply'); // 'multiply' (ON) | 'source-over' (OFF) ink.setInkDensity(0.97); // 97% density, 3% see-through ink.setBlendIntensity(0.45); // how far crossings mix ink.setOverprintAttack(0.85); // in fast … ink.setOverprintRelease(0.55); // … out slowly ink.setOverprintSwell(0.075); // the active instrument's crossing swell ink.setAgentPen(1, { preset: 'posca_squeezer_thin', color: '#E60000' }); // an agent's own pen
